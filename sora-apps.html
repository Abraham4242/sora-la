04 · CÓMO USAR EL MCP
04 · HOW TO USE THE MCP

Conectar Claude Code en 30 segundos.

Connect Claude Code in 30 seconds.

El MCP server ya está construido. Solo falta registrarlo en Claude Code y proveer el token Apify.

The MCP server is already built. Just register it in Claude Code and provide the Apify token.

# 1. Obtener APIFY_TOKEN (gratis ~$5 credito inicial)
#    → apify.com → sign up → console → settings → integrations → API token

# 2. Setup local del MCP
cd ~/sora-instagram-mcp
cp .env.example .env
# Editar .env con tu APIFY_TOKEN

npm install
node server.js # validar que arranca sin error

# 3. Registrar en Claude Code
claude mcp add sora-mining "node" "/Users/jacobeid/sora-instagram-mcp/server.js"

# 4. Verificar
claude mcp list # debería mostrar sora-mining

# 5. Usar desde cualquier sesión Claude Code
claude # abre sesión nueva
→ "minar comentaristas de @habitas_tulum últimos 10 posts"
→ MCP corre · regresa lista scored
NOTA · COST-CAP GUARDS NOTE · COST-CAP GUARDS

El MCP tiene SORA_COST_CAP_USD environment var (default $5/sesión). Si una llamada va a exceder eso, el server rehúsa y avisa. Para llamadas mayores: SORA_COST_CAP_USD=20 node server.js. Protege contra accidentes de scraping caro.

The MCP has a SORA_COST_CAP_USD env var (default $5/session). If a call would exceed that, the server refuses and warns. For bigger calls: SORA_COST_CAP_USD=20 node server.js. Protects against accidental expensive scraping.
