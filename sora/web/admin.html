Cómo publicar tus cambios

Importante: Cuando agregás propiedades o cambiás la configuración acá, los cambios se guardan SOLO en este navegador. Para que los vean OTRAS personas que visitan el sitio, tenés que publicarlos. Te enseño cómo abajo.

Opción 1 · La fácil (usar como demo local)

Si sólo querés probar la web en tu navegador, no necesitás publicar nada. Los cambios ya se ven cuando abrís index.html en este navegador.

Opción 2 · Para que TODO EL MUNDO vea tus propiedades

Cuando subas la web a internet (Netlify, etc.), seguí estos pasos:

  1. Tocá el botón "EXPORTAR TODO" arriba a la derecha.
  2. Se va a descargar un archivo sora-data.js.
  3. Subilo a la misma carpeta donde está index.html.
  4. Listo. Ahora todos los visitantes ven tus propiedades.
Cada vez que agregues o cambies una propiedad, repetí estos pasos. Es como "guardar el cambio para todos".

Subir fotos · qué recomiendo

Para fotos de propiedades, usá una de estas opciones:

  • Imgur (gratis, sin cuenta) — entrá a imgur.com, arrastrás la foto, copiás el link directo.
  • Instagram público — abrí la foto, click derecho > "Copiar link de la imagen".
  • Google Drive con link público — sube la foto, click derecho > "Obtener link" > "Cualquiera con el link".

Tip: las fotos pesadas hacen lenta la web. Usá fotos de máximo 1500px de ancho.
